# Sprint log

Historial de sprints completados. Cada entrada es un sprint cerrado, con su objetivo,
entregables y lessons emergentes. Sprint en curso NO va acá — va a notas de trabajo
sueltas o a `decisions.md` si toma decisiones formales.

Formato por entrada:

```
## Sprint N — <título>

**Fechas:** YYYY-MM-DD a YYYY-MM-DD
**Objetivo:** Una línea sobre qué buscaba el sprint.
**Entregables:**
- item 1
- item 2

**Lessons emergentes:**
- lección breve (la versión completa va a lessons.md)
```
