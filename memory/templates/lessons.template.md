# Lessons aprendidas del proyecto

Lessons que emergieron trabajando este proyecto. Lo que está acá es local: vale
para este proyecto. Si una lessons aplica a TODOS los proyectos del usuario, va a
la memoria global (`~/.claude/projects/.../memory/lessons/`), no acá.

Formato por entrada:

```
## <título de la lección>

**Contexto:** Qué situación la generó. Una o dos frases.
**Lección:** Lo aprendido, en imperativo si se puede ("nunca X", "siempre Y").
**Cómo aplicarla:** Acción concreta para la próxima vez.
**Fecha:** YYYY-MM-DD
```
